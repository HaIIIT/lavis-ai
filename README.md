# LAVIS AI — UI/UX Redesign

Bản thiết kế lại giao diện website LAVIS AI trên nền tảng HTML, CSS và JavaScript thuần hiện có.

## Chạy thử
1. Giải nén thư mục.
2. Mở bằng VS Code.
3. Chạy bằng Live Server hoặc `npx serve .`.
4. Truy cập đường dẫn server cung cấp; điều hướng `/product` và `/about`.

## Giao diện
- `/product`: Landing page giới thiệu hệ sinh thái sản phẩm, công nghệ và form tư vấn.
- `/about`: Giới thiệu định hướng, giá trị và đội ngũ phát triển.
- Responsive cho desktop, tablet và mobile.
- Icon dùng thư viện Lucide.
- Logo thương hiệu đặt tại `assets/lavis-ai-logo.png`.

## Lưu ý
Đây là UI prototype. Form tư vấn hiện chỉ hiển thị phản hồi demo, chưa lưu dữ liệu hoặc gửi email. Ảnh minh họa trong trang sản phẩm tải từ Unsplash. Cần thay bằng ảnh sản phẩm thật và thông tin liên hệ chính thức trước khi công bố.
